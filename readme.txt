# Employee Management System

A full-stack Employee Management System designed to efficiently manage employee records through CRUD operations. The application allows users to add, update, delete, and view employee information through an intuitive interface.

## Features

- Add new employees
- View employee records
- Update employee details
- Delete employee records
- Search and manage employee information
- User-friendly interface

## Tech Stack

### Frontend
- HTML5
- CSS3
- Bootstrap

### Backend
- PHP

### Database
- MySQL
